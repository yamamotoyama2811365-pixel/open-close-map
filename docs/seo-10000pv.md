# 月間10,000PVに向けた改善記録

更新: 2026-09-10 / 対象: 開店閉店マップ

## 目標と未計測事項

目標はサイト全体で月間10,000PV。30日換算では約333PV/日。これは目標であり、現在の実績・達成予測ではない。検索クリック数、訪問数、PVは別の指標として扱う。

GA4プロパティ553356360の一覧上の存在は確認できたが、詳細取得と2026-08-11〜2026-09-09のレポート取得がともに「authorization has expired or been revoked」で失敗した。現在PV、自然検索流入、回遊率は未確認。測定IDは既存のG-ZB4T13GM5Pを保持。サイト上のタグ修正と、分析ツール側の再認証は別の作業。

## 2026-09-10 第1弾

- トップの地域6件・業種6件を最初のHTMLから存在する通常のリンクに変更。
- 動的な店舗カード、直近情報、業種一覧、全国動向の業種を通常のリンクに変更。Ctrl/Cmdクリックやキーボード操作を妨げない。
- クリック計測は既存のdata-ga-eventの仕組みに統一し、独自の画面遷移コードを除去。
- サイト名のWebSite構造化データ、OGP、明示的なrobots指定を追加。架空の評価、順位、店舗情報は追加しない。
- 元のレイアウト・画像・広告・訂正窓口と共用APIを維持。主画像に読み込み優先度を指定したが、速度改善は未実測。
- 計測設定APIのHTTPエラー、JSONエラー、無効なID、ネットワーク障害、3秒タイムアウトで既存IDにフォールバック。同じスクリプトを再読み込みしても初期化を重複させない。
- データ抽出・掲載判定・データベース・料金プランは変更しない。

静的HTML中の重複しない内部リンク先（ルートから始まりフラグメントを含まないhref）は6から18に増加。動的カードはこの数に含めない。この指標はクロールしやすさの確認用であり、検索登録数や検索順位ではない。

## 検索需要の参考値と次の判断

2026-09-10にHYPDのresearch_get_search_volumeで日本・日本語を指定。取得された月間検索数の推定値: 「開店閉店」18,100、「札幌 閉店」1,900、「札幌 開店」480、「福岡 閉店」720、「大阪 閉店」480、「ラーメン 新店」1,300。付属の月別データは2025年8月〜2026年7月。自サイトのPV予測ではなく、類似語間の重複を考慮せず合算しない。広告のcompetition指標をSEO難易度として使わない。

全国の大きな語だけを追わず、「店舗名＋開店/閉店」と「地域＋閉店」を改善候補とする。重点地域は、既存データの件数・鮮度とSearch Consoleの実際の表示・順位を見て決める。確認前に全国一律の薄いページを増やさない。

再認証後の順序:
1. GA4で対象ホストの30日PV、自然検索訪問、詳細ページへの回遊を計測する。
2. Search Consoleでサイトマップ処理、検索登録状況、表示回数・クリック・検索語を確認する。提出済み・登録済みとは未確認のまま断定しない。
3. 表示はあるがクリックされないページは、実データに合ったタイトル・要約を検証する。登録されないページは先に内容の重複・情報不足・正規URL・応答を点検する。
4. 読まれた地域・店舗を軸に、掲載元、日程、所在地、関連店舗への導線を改善する。不明な閉店理由や後継テナントを推測で埋めない。
5. 変更日ごとの7日/28日比較を蓄積する。検索需要の季節変化や記事追加件数の違いも区別し、PVを不自然な再読み込み等で水増ししない。

自動で継続監視・記事修正するジョブはこの変更には含まれていない。
