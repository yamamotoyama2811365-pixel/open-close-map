## 保存されるもの

日本時間の日付、既存掲載ページのパス、参照元の分類、テスト区分、集計PV数のみ。
参照元の分類: google / yahoo / bing / direct_or_unknown / referral / internal。
Cookie、閲覧者ID、IPアドレス、検索語、完全な参照元URLを独自PV集計には保存しない。参照元はブラウザ内で分類し、分類名だけ送信する。
DNT/GPC・既知のボット・非表示ページに対する除外と、同一ドキュメント内の重複送信防止を実装。通信失敗を再送してPVを重複させない。
この説明は独自計測の範囲。既存のGA4、広告、ホスティングの接続ログとは別で、サイト全体がCookieや接続情報を一切扱わないという意味ではない。privacy.htmlに追記済み。

## 指標・運用上の注意

計測開始は2026-09-11。開始前のPVは復元しない。開始日や当日は途中のデータであり、完全な1日/30日実績とは扱わない。
既定レポートは日本時間で昨日までの直近30日。include_today=trueなら当日途中を含むことを明示する。
参照元は各ページの直前の参照情報で、訪問全体の流入元を追跡したものではない。direct_or_unknownは直接訪問と参照元を取得できないアクセスを区別できない。
この仕組みは概算PV用。ユニークユーザー数やセッション数を測らず、すべてのボット・不正送信・計測遮断を判別できるものではない。GA4とは定義も異なるため単純合算しない。
月間10,000PVは目標であり、達成を確認したものではない。
自動で稼働するのは閲覧数の記録と、呼び出し時の集計。毎週月曜にChatGPTが自律的に起動する設定や、SEOコードを自動改修・公開する設定は今回追加していない。
